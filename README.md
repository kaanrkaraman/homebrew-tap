# kaanrkaraman/tap

Homebrew formulae by Recep Kaan Karaman.

| Formula | Description |
|---|---|
| [nblean](https://github.com/kaanrkaraman/nblean) | Token-lean Jupyter notebook access for coding agents |

```bash
brew install kaanrkaraman/tap/nblean
```

Or tap once with `brew tap kaanrkaraman/tap`, then `brew install nblean`.

## Apps

| Cask | Description |
|---|---|
| [damla](https://github.com/kaanrkaraman/damla) | Safari extension for downloading videos from social sites (macOS 14+) |

```bash
brew install --cask kaanrkaraman/tap/damla
```

The app updates itself.
